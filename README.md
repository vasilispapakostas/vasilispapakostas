# Vasileios Papakostas

Computing for Business student at DCU, based near Dublin.

I spent this summer as an Undergraduate Research Assistant at UCD's Laboratory for Intelligent Manufacturing and Robotics, programming and debugging Dobot Magician and UR5e arms in Python. Alongside that I worked as an operator at a medical device manufacturer, using SAP to record production and quality data in a GMP-controlled environment.

### Projects

- **[UR5e Visual Servoing](https://github.com/vasilispapakostas/UR5e-camera-control)**: closed-loop visual servoing prototype for a UR5e industrial arm, using ArUco markers for metric scale, HSV segmentation for target detection, a proportional control loop, and safety checks for movement limits, tool tilt and camera loss
- **[Customer Churn Dashboard](https://github.com/vasilispapakostas/customer-churn-dashboard)**: Streamlit dashboard that segments customers by contract, tenure and usage, ranks them by the lower bound of annual revenue at risk so a small segment cannot top the table on noise, and tests whether a retention campaign clears its own cost.
- **[Dobot Colour-Sorting Conveyor](https://github.com/vasilispapakostas/dobot-color-sorter)**: sorts coloured cubes off a running conveyor using an infrared sensor, a colour sensor, and a suction end effector
- **[TechPodcasts](https://github.com/vasilispapakostas/techpodcasts)**: Django app for finding and reviewing tech podcasts, with auth, ownership rules, and star ratings
